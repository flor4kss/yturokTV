# 📺 yturokTV — Персональное Виртуальное ТВ 24/7

> **«2х2, Jetix и Anime Золотой Эпохи, какими они должны быть»**

Веб-приложение линейного псевдо-телевидения (Virtual Linear TV) со своей синхронизированной сеткой вещания, переключением каналов, интерактивной ТВ-программой (EPG) и интеграцией с базой **AniLibria** и **YouTube**.

---

## ⚡ Преимущества концепции над обычными сайтами

1. **Никакого «паралича выбора»**: не нужно 40 минут выбирать тайтл в каталоге — нажал кнопку, и сразу идёт серия.
2. **Идеальный фоновый просмотр**: во время еды, готовки, кодинга или отдыха сериал идёт сам, серия за серией.
3. **Эффект случайных находок**: натыкаешься на шедевры и культовые мультфильмы, которые сам бы не вспомнил включить.
4. **Межпрограммные отбивки и бамперы**: ностальгические чёрно-белые заставки старого 2х2, Adult Swim и реклама 2000-х между сериями.
5. **Синхронный просмотр 24/7**: все зрители в мире смотрят ровно одну и ту же секунду благодаря детерминированной математической синхронизации по часам (Unix Epoch).

## 🎯 Твёрдая база контента: откуда берётся видео

| Источник | Формат | Что транслирует | Плюсы |
|---|---|---|---|
| **AniLibria API** | Прямой HLS `.m3u8` (720p / 1080p) | Вся база современного и классического аниме с русской озвучкой | Полноценный API, живой поиск, бесплатный CDN без авторизации и рекламы |
| **YouTube API** | IFrame Embed с синхронизацией секунды | Ретро-мультфильмы Jetix, Fox Kids, Avatar, бамперы 2х2 | Огромная библиотека, мгновенная загрузка |
| **Archive.org** | Прямой `.mp4` | Оцифровки эфиров 90-х / 2000-х, классика анимации Флейшера | Без цензуры и с оригинальной атмосферой |
| **Пользовательский ввод** | Любой YouTube URL или ID | Ваши личные серии и передачи | Добавляется в 1 клик на **Кнопку 05 («Мой Канал»)** |

## 🕹️ Управление с клавиатуры (как настоящий пульт ДУ)

* `1`, `2`, `3`, `4`, `5` — прямое переключение на соответствующий канал.
* `Стрелка Вверх` / `Стрелка Вниз` или `Влево` / `Вправо` — переключение каналов по кругу (CH+ / CH-).
* `M` — вкл / выкл звук (Mute).
* `F` — полноэкранный режим (Кинотеатр).

## Интерфейс на React

React 19, Vite 8, Tailwind CSS 3. Стили и HLS.js входят в сборку. YouTube IFrame API и шрифты Google загружаются отдельно.

`src/components` содержит шапку, список каналов, видеозону, информацию о передаче, боковую панель, телепрограмму и управление эфиром. Динамические списки и поиск каталога отрисовываются React; сообщения выводятся как текст, а не HTML.

`src/tvController.js` сохраняет существующую логику расписания, синхронизации, YouTube/HLS/MP4, управления звуком, таймера сна и летящих комментариев. Он передаёт данные React-компонентам. Настройки и управление медиаплеером пока остаются в этом модуле; перенос интерфейса не меняет алгоритм эфира.

## Запуск

Нужны Node.js 22.12+ (или 24) и Python 3.

```sh
npm ci
npm run build
python server.py
```

В Windows можно запустить `run.ps1`: он устанавливает зависимости, собирает интерфейс и запускает сервер. Сервер открывает браузер на localhost:8080; если порт занят, выбирает следующий свободный.

Для разработки:

```sh
# Терминал 1: API
python server.py
# Терминал 2: React с обновлением при редактировании
npm run dev
```

Vite направляет запросы /api на localhost:8080. Если сервер выбрал другой порт, измените адрес в `vite.config.js`.

## Размещение

`npm run build` создаёт папку `dist` и копирует готовые `index.html` и `assets` в корень репозитория. Это сохраняет существующую публикацию GitHub Pages из ветки main без изменения настроек. Исходная HTML-точка входа находится в `src/index.html`; корневой `index.html` генерируется сборкой. После изменения интерфейса выполните сборку и включите обновлённые файлы в коммит.

Vercel настроен собирать и публиковать `dist`. Для Cloudflare Pages также укажите `dist`. Относительные пути сборки поддерживают размещение в подпапке репозитория.

Статический хостинг поддерживает воспроизведение, встроенную сетку и локальные настройки. Общий чат, серверное время и сохранение общей сетки требуют отдельно размещённого Python API. Для публичного API требуется авторизация управления расписанием; исходный локальный сервер её не реализует.

## Проверка переноса

Проверены production-сборка, переключение каналов, открытие и закрытие телепрограммы и панели управления, отправка и безопасный вывод текста чата. Браузерная проверка выполнялась с заглушками внешних ресурсов; доступность реальных YouTube/AniLibria/Archive.org потоков этой проверкой не подтверждается.
