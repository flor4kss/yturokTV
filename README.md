# yturokTV — твоя уютная волна

Виртуальное телевидение с общей сеткой эфира: аниме, мультфильмы, музыка и стримы. История уже идёт — достаточно включить канал.

## Интерфейс

React 19, Vite 8, Lucide React, собственная адаптивная CSS-система. Светлая кремовая палитра с мятными и коралловыми акцентами, оригинальная иллюстрация, мягкие переходы и тихие синтезированные звуки нажатий. Вечерняя тема, избранное и настройка звуков сохраняются в браузере. Системное предпочтение уменьшенного движения отключает анимации и летящие комментарии.

- Поиск каналов и передач, фильтры по категории и избранному.
- YouTube, HLS и MP4: громкость, просмотр с начала, возвращение в эфир, кинотеатр и полный экран.
- Телепрограмма на сегодня, завтра и послезавтра с временем Екатеринбурга.
- Чат с безопасным выводом текста, комментарии на экране, таймер сна и CRT-эффект.
- Поиск в AniLibria и добавление серий в выбранный канал через «Моя комната → Собрать свою сетку эфира».
- Управление с клавиатуры и доступные диалоги с удержанием фокуса и закрытием через Escape.

`src/ui` содержит интерфейс; `src/App.jsx` связывает экраны и настройки. `src/tvController.js` управляет расписанием и медиадвижками и публикует состояние через `useSyncExternalStore`. Медиаплееры используют отдельные DOM-узлы, а весь интерфейс отрисовывается React. `src/sound.js` синтезирует короткие отклики через Web Audio после действий пользователя.

## Пульт

| Клавиша | Действие                     |
| ------- | ---------------------------- |
| ↑ / ↓   | Предыдущий / следующий канал |

| M | Выключить / включить звук эфира |
| F | Полный экран |
| Escape | Закрыть диалог |

Пульт не перехватывает ввод в полях, кнопках и открытых диалогах. Кнопка «В эфир» возвращает к общей временной сетке.

## Запуск

Нужны Node.js 22.12+ или 24 и Python 3.

```sh
npm ci
npm run build
python server.py
```

В Windows можно запустить `run.ps1`: он устанавливает недостающие зависимости, собирает интерфейс и открывает локальный сервер. Сервер обычно работает на localhost:8080; если порт занят, выбирает следующий свободный.

Для разработки запустите `python server.py` и `npm run dev` в отдельных терминалах. Vite направляет `/api` на localhost:8080. Если Python выбрал другой порт, обновите адрес в `vite.config.js`.

## Публикация

`npm run build` создаёт `dist`, затем копирует готовые `index.html`, `assets` и `art` в корень репозитория. GitHub Pages публикуется из main. Включайте результат сборки в коммит. HTML-исходник находится в `src/index.html`; корневой `index.html` генерируется автоматически. Иллюстрация хранится в `public/art`, а `art` — её опубликованная копия.

Vercel и Cloudflare Pages могут публиковать `dist`. Относительные пути поддерживают размещение в подпапке.

На статическом GitHub Pages настройки, избранное, личная сетка и сообщения сохраняются в браузере; чат синхронизируется между вкладками этого устройства. Общий чат и сохранение общей сетки работают при доступном Python API. Доступность роликов и потоков зависит от внешних источников. Локальный Python-сервер не реализует авторизацию управления расписанием — для публичного общего API её нужно добавить.

## Проверка

Production-сборка и браузерные сценарии на компьютере и телефоне: отсутствие горизонтального переполнения, переключение и поиск каналов, избранное, телепрограмма, возврат фокуса, настройки звука/темы/CRT/комментариев, таймер, кинотеатр, безопасный текст чата, сохранение настроек, просмотр с начала и добавление релиза из каталога. Проверки внешних API используют заглушки и не подтверждают доступность каждого видео.
