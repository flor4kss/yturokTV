# yturokTV для Google TV

Универсальный APK для ручной установки на Google TV / Android TV. Приложение появляется в телевизионном меню, открывает актуальный сайт в отдельном ТВ-режиме и работает без мыши. Для просмотра нужен интернет и установленный системный Android System WebView.

## Пульт

- Стрелки: перемещение выделения по кнопкам.
- OK: выбранное действие; во время просмотра без меню — список каналов.
- Назад: закрыть окно, скрыть управление; повторное нажатие предлагает выход.
- Channel + / −, если есть на пульте: смена канала.
- Громкость телевизора: стандартные кнопки пульта. Громкость приложения: стрелки влево/вправо на выделенном ползунке.

Приложение приостанавливает воспроизведение при уходе в фон и возвращается к текущему общему эфиру при возобновлении. Сайт может обновляться без переустановки APK. При обновлении самого APK требуется тот же ключ подписи и увеличенный versionCode.

## Сборка

Android platform 35, build tools 35.0.0, JDK 17. Локальные пути задаются в `.tools/android/paths.json`. Запустить `python android-tv/build.py` из корня проекта. Готовый файл: `downloads/yturokTV-GoogleTV.apk`. Ключ подписи и его пароль находятся только в `.tools/android`, исключённом из Git; их нужно сохранить для последующих обновлений APK.

У приложения нет доступа к файлам телевизора, микрофону или аккаунтам: требуется только интернет. Подпись APK проверяется при сборке. Проверка управления выполняется в браузере; реальный телевизор и его аппаратные декодеры отдельно не тестировались.

## Версия 1.1

Прямые публичные потоки Rutube запрашиваются приложением при просмотре канала с Rutube. Посредник ограничен API play/options, bl.rutube.ru и поддоменами rtbcdn.ru; разрешаются только HTTPS GET из страницы yturokTV. Временные ссылки обновляются при воспроизведении, а не хранятся в библиотеке. ПК и телефоны используют официальный iframe; исправление обработки preroll применяется на всех устройствах. При недоступности прямого потока приложение возвращается к iframe. Аппаратное воспроизведение новой версии требует проверки на телевизоре.
