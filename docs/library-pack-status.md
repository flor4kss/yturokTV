# Кандидат обновления: выпуск не завершён

RUTUBE исключён из источников кандидата по указанию пользователя. Доступный URL, загруженный iframe и метаданные не считаются подтверждением воспроизведения. Новые проверки этого провайдера остановлены. «Подозрительная сова» сохраняется в каталоге кандидата со статусом excluded; в минимум работающих сериалов не входит.

Проверка декодирования не означает просмотр всего сезона. Эмуляция мобильного экрана не заменяет проверку физического телефона. Проверка ограниченной скорости для новых источников ещё не выполнена. У найденного MP4 не подтверждены варианты низкого качества.

## Подготовлено в исходниках

- Очередь по одной серии каждого сериала за круг, детерминированная смена порядка и отметки повторов после полного обхода.
- Блокировка сюжетной последовательности перед исключённой или пропущенной серией; независимые выпуски могут пропускать неисправные записи.
- Сохранение прежнего расчёта сетки для перехода на границе целой передачи с рекламой и продолжением.
- Подготовка кандидата с устойчивыми ID эпизодов, отдельными версиями библиотеки и сетки, начальными позициями из прежних показов.
- Обновление метаданных теперь сохраняет результат отдельно, а не поверх действующей библиотеки.

## До завершения выпуска

1. Нужны два новых сериала с проверенными полными первыми сезонами на русском. Сейчас подтверждённого комплекта нет; «Мульт Грань» остаётся на уровне 1/3.
2. Нужны полная проверка новых эпизодов, продолжений аниме и семейных мультфильмов, журнал доказательств и окончательный допуск пакета.
3. Ещё не реализован переход на резервный сериал после исчерпания источников неисправной серии.
4. Нужны итоговые проверки приложения и ограниченного соединения, публикация и подтверждение версии сайта.

Кандидат `.tools/candidate-pack/pack.json` не активирован. Действующие schedule.json, channels.js и опубликованный сайт не заменены. APK и музыкальный канал не изменялись.
