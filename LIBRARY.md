# Источники библиотеки

`library-sources.json` задаёт порядок доступных сезонов и проверенные коллекции мультфильмов. `python scripts/sync-library.py` обновляет эпизоды, длительность, качества 480/720/1080 и адреса серверов коллекций. `python scripts/check-library-sources.py` проверяет один эпизод каждого релиза и заголовки новых MP4. Отчёт отличает метаданные и доступность заголовков от полного воспроизведения.

Библиотека содержит только эпизоды с опубликованным источником и длительностью. Ошибка API сохраняет прежний релиз. Автоматического поиска произвольных роликов нет. K-On! второго сезона в текущем источнике нет. У Фиксиков импортировано 47 файлов с корректной длительностью; пять файлов коллекции не прошли этот фильтр. Выпуски русского DVD Лунтика подписаны как выпуски сборника, а не вымышленные номера канонических серий.

Сезоны одного сериала используют общий seriesKey и следуют порядку releaseId в конфигурации. Эфир продолжается от общего начала сетки: добавление сезона не перескакивает немедленно к нему. У добавленных эпизодов без проверенного места рекламной паузы нет искусственного разрезания посреди сцены.

Выбор качества и ошибки источников локальны для зрителя. Google TV предпочитает 480p; при отказе URL плеер пробует другое качество или адрес файла. Разные качества одного CDN и адреса одной коллекции не являются независимыми поставщиками контента.

Rutube на всех устройствах использует официальный iframe с учётом preroll и без перемотки во время рекламы. APK не изменяется.

Музыкальный канал по-прежнему использует YouTube. Проверенные идентификаторы архивных копий текущих 18 роликов не дали доступных MP4; замена этих источников пока не найдена. Анонсы могут показывать короткое видеопревью из серии при недоступном YouTube-трейлере.

## Устойчивое воспроизведение

По умолчанию задержка выключена на всех устройствах. После ожидания 8 секунд или двух остановок за минуту сайт предлагает её включить. Отказ убирает предложение до конца посещения. Включение явно пользователем накапливает запас не менее 10 секунд по времени ожидания и целится в 15 секунд видео после остановки; эфирный отсчёт при загрузке замораживается. Режим не включается автоматически и не сохраняется между посещениями.

Для аниме с несколькими качествами собирается адаптивный HLS master playlist из HTTPS-ссылок поставщика. Авто начинает с низкого качества, оценивает скорость по фрагментам и учитывает реальный битрейт, повышая качество осторожно. Наилучшее выбирает максимальный вариант источника, низкое — ближайший к 480p. Фактическое разрешение может быть ниже номинального. Источники с одним качеством и внешние плееры показывают ограничение в селекторе. При отсутствии HLS.js нативный браузер использует доступную ссылку без обещания полной автоматической адаптации.

Цель буфера: 60 секунд обычно, 120 секунд в режиме задержки, с пределом памяти 48 МБ. Запуск — после 5 секунд доступного видео; повторное заполнение — 8 секунд (15 с задержкой). В конце файла порог уменьшается. Нативный MP4 может ограничивать предварительную загрузку: после 5 секунд (12 в режиме задержки) разрешается продолжить при готовом кадре с меньшим доступным запасом. Плеер повторяет загрузку фрагментов с паузами, затем пробует другой вариант источника, сохраняя позицию. Коррекция по часам допускается только в уже загруженный диапазон с запасом минимум 8 секунд, при отставании больше 15 секунд и выключенной задержке.

При слабой сети / низком качестве видеоанонсы заменяются статичным оформлением; новые обложки откладываются, частота комментариев снижена. Следующая передача не загружается параллельно текущей. Изменений APK нет.
