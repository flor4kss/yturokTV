## Как работает эфир сейчас

Сериалы чередуются по одному эпизоду: первая серия каждого, затем вторая и т.д. Второй сезон включается после доступных серий первого. Одинаковые ссылки внутри одного сериала удалены; это не доказывает, что оставшиеся файлы не содержат одинаковые кадры. Полнота сезонов и работоспособность всех старых источников ещё требуют отдельной проверки.

Музыкальный канал проигрывает блок «Аниме-звук», затем блок «Крафт-хиты». Длительность блока определяется суммой клипов; часовые блоки пока не вводятся, поскольку музыкальная библиотека мала.

Расписание общее для всех зрителей, рассчитывается по времени Екатеринбурга и реальным полям длительности записей. Обновление страницы не начинает очередь заново. По окончании всей библиотеки канал повторяет цикл; повтор отмечен в плеере и программе. Фиксированной недельной сетки и ежедневных премьер пока нет. Взрослый мультканал особенно нуждается в пополнении, иначе повторов будет много.

## Эфирные вставки

Шуточная реклама убрана. Для серий длиннее четырёх минут один 18-секундный анонс стоит на 45% длительности. Эфир содержит первую часть, анонс и вторую часть с sourceOffset: продолжение начинается с точки остановки, а не с начала и не с пропуском 18 секунд видео. На музыкальном канале анонсы остаются между блоками, чтобы не разрывать песни.

Анонс рекламирует следующую передачу после завершения текущей серии. Время учитывает и остаток анонса, и вторую часть серии. Все зрители видят одну и ту же сетку; время Екатеринбурга. У анонса есть слоган по теме тайтла, постер с медленным движением, фоновая инструментальная мелодия. Подложка синтезируется в браузере, меняет темп и регистр по каналу и учитывает громкость/отключение звука. Дикторская озвучка пока не добавлена.

Изображение берётся из метаданных тайтла, для музыкальных клипов используется YouTube-обложка. Если обложки нет, приложение запрашивает изображение страницы по названию через Wikipedia API. Если и этот источник недоступен или не возвращает изображение, остаётся оформление с названием и графикой.

Проверки: разрезание серии без потери длительности, точная позиция продолжения, отсутствие шуточных вставок, анонс реального следующего тайтла, время после полуночи. Проверка браузера использует имитацию видео для проверки перехода в анонс и продолжения; это не проверка доступности всех внешних HLS-источников.
